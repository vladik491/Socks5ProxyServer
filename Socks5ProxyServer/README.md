# SOCKS5 Proxy Server with Accounting

Курсовой проект по дисциплине «Сетевые технологии и системное программирование».
Высокопроизводительный асинхронный SOCKS5-прокси сервер на платформе .NET 8 (C# 12) с обязательной аутентификацией, потокобезопасным учетом трафика и контролем одновременных подключений.

## 1. Требования технического задания

1. Реализация бинарного протокола SOCKS5 в соответствии с RFC 1928 (команда TCP CONNECT).
2. Поддержка целевых адресов формата IPv4 и FQDN (доменные имена).
3. Аутентификация клиентов по логину и паролю в соответствии с RFC 1929 (метод 0x02).
4. Потокобезопасный учет сетевого трафика по каждому пользователю: объем переданных и принятых байт, активные сессии, посещенные хосты.
5. Ограничение максимального количества одновременных подключений на одного пользователя.
6. Асинхронная неблокирующая обработка ввода-вывода (async/await, NetworkStream).

## 2. Архитектура и реализация

Проект спроектирован по модульному принципу:

- Protocol: парсинг бинарных пакетов RFC 1928/1929, валидация версий, Big-Endian декодирование портов и генерация статусных кодов (0x00, 0x01, 0x02, 0x05, 0x08).
- Relay: двунаправленная асинхронная ретрансляция потоков с использованием пула буферов ArrayPool и отключением алгоритма Нагла (NoDelay = true).
- Stats: Lock-Free учет сетевых байт (Interlocked.Add) и ограничение одновременных подключений через CAS-цикл (Interlocked.CompareExchange). Встроена защита от DoS-переполнения памяти при переборе хостов.
- Core: сетевой слушатель на базе TcpListener, конвейер клиентской сессии, событийное цветное логирование и загрузка настроек из файла users.json.
- Tests: набор из 16 модульных тестов xUnit и автоматизированный скрипт интеграционного тестирования test_all.bat.

## 3. Результаты работы

- Сервер успешно маршрутизирует TCP-трафик для клиентских программ (утилита curl, браузеры).
- Обеспечена изоляция пользовательских сессий и корректное отклонение неавторизованных запросов.
- Реализован строгий сброс соединений при превышении лимита активных сессий (код 0x02).
- Все 16 модульных тестов xUnit выполняются успешно без сбоев.

## 4. Инструкция по сборке и запуску

### Требования
- .NET 8.0 SDK или Visual Studio 2022 (версия 17.8 и выше).

### Клонирование репозитория
git clone https://github.com/vladik491/Socks5ProxyServer.git
cd Socks5ProxyServer

### Запуск сервера
Вариант 1 (Visual Studio 2022): открыть Socks5ProxyServer.sln и нажать Ctrl + F5.
Вариант 2 (консоль): dotnet run --project Socks5ProxyServer

Сервер запустится на порту 1080. Пользователи и лимиты загружаются автоматически из файла users.json.
Для корректной остановки сервера нажмите Ctrl + C.

### Запуск тестирования
1. Интеграционное тестирование: при запущенном сервере запустить файл test_all.bat. Скрипт последовательно проверит авторизацию, FQDN-маршрутизацию, отказ при неверном пароле и блокировку при превышении лимита сессий.
2. Модульные тесты: в Visual Studio нажать Ctrl + R, A (или выполнить команду dotnet test в консоли).
