# SOCKS5 Proxy Server with Accounting

Асинхронный SOCKS5-прокси сервер на C# (.NET 8) с авторизацией по логину и паролю, потокобезопасным учетом трафика и ограничением одновременных подключений.

## Возможности

- Поддержка протокола SOCKS5 (RFC 1928, команда CONNECT).
- Маршрутизация трафика по IPv4 и доменным именам (FQDN).
- Аутентификация по логину и паролю (RFC 1929).
- Потокобезопасный учет переданных байт, сессий и посещенных адресов.
- Ограничение числа одновременных подключений на пользователя.
- Неблокирующий асинхронный ввод-вывод (async/await, NetworkStream, ArrayPool).
- Хранение учетных записей и лимитов в файле users.json.

## Архитектура

- **Core** — сетевой слушатель (TcpListener), управление сессиями и конфигурация.
- **Protocol** — бинарный разбор протокола RFC 1928 / RFC 1929.
- **Relay** — асинхронная двунаправленная пересылка трафика.
- **Stats** — потокобезопасный учет байт и Lock-Free контроль лимитов (Interlocked).
- **Tests** — набор модульных тестов xUnit (16 тестов).

## Быстрый старт

Требования: .NET 8.0 SDK или Visual Studio 2022.

```bash
# 1. Клонирование репозитория
git clone https://github.com/vladik491/Socks5ProxyServer.git

# 2. Запуск сервера (порт 1080)
dotnet run --project Socks5ProxyServer

# 3. Запуск модульных тестов
dotnet test
```

Для комплексной проверки всех сценариев работы сервера (включая проверку лимитов) запустите скрипт `test_all.bat`.
